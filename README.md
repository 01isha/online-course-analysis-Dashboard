#EdTech Startup Data Analysis
An interactive Power BI data analytics dashboard designed to analyze online course data for an EdTech startup, focusing on course categories, learner engagement, skills, languages, instructors, subtitles, and course duration.

The EdTech Startup Analytics Dashboard is an interactive Power BI report designed to help an EdTech company understand its online course offerings and learner engagement.
The dashboard analyzes course performance across different categories, sub-categories, languages, skills, instructors, ratings, subtitles, and course durations to identify patterns and provide insights that can support decisions around content creation, instructor selection, and course strategy.

Tech Stack
The dashboard was built using the following tools and technologies:
• Power BI Desktop – Main platform used to create the interactive dashboard and data visualizations.
• Power Query – Used for data cleaning, transformation, formatting, and preparation.
• DAX (Data Analysis Expressions) – Used to create calculated measures, conditional logic, rankings, and analytical calculations.
• Data Modeling – Used to structure the dataset and create the necessary relationships and calculations for analysis.
• Power BI Visualizations – Used to create interactive charts, slicers, cards, tables, and other visuals for exploring course data.

Data Source
The project uses Kaggle Dataset

Business Problem
An EdTech startup offering recorded online courses needs to understand its existing course portfolio and learner engagement in order to make better decisions about course categories, skills, languages, instructors, and content strategy.
With a large number of courses across different categories and formats, it can be difficult to identify which areas attract the most learners and which characteristics are associated with higher engagement.
Key questions such as:
- Which course categories and sub-categories are most popular?
- Which categories receive the highest average views?
- Which skills are most commonly taught?
- Which languages are most frequently used?
- Do subtitles affect course engagement?
- Which instructors have the highest ratings?
- How does course duration relate to views?
- Which categories should receive more attention?
are difficult to answer efficiently using raw data alone.

Goal of the Dashboard
The goal of this dashboard is to provide an interactive analytical tool that:
- Analyzes the distribution of courses across categories and sub-categories.
- Identifies categories with higher learner engagement.
- Determines the most commonly taught skills.
- Examines language distribution across courses.
- Analyzes the relationship between subtitles and course views.
- Identifies highly rated instructors.
- Examines the relationship between course duration and views.
- Helps the EdTech business understand its course portfolio and learner engagement
- Walkthrough of Key Visuals
- Course Distribution by Category & Sub-category
Analyzes how courses are distributed across different categories and sub-categories to understand the overall structure of the EdTech platform's content.
- Average Views by Category
Compares the average number of views across different course categories to identify areas with stronger learner engagement.
- Average Views by Sub-category
Provides a more detailed view of learner engagement by analyzing average views across individual sub-categories.
- Skills Analysis
Identifies the most frequently taught skills across courses and categories, helping understand the skills emphasized within the platform's content.
- Language Distribution
Analyzes the distribution of courses across different languages to understand the platform's language coverage.
- Language Preference by Category
Examines language distribution within the top course categories to understand how language preferences vary across different areas of learning.
- Subtitle Analysis
Compares course engagement based on subtitle availability to examine whether subtitles are associated with differences in course views.
- Top Instructors
Identifies highly rated instructors across different categories and sub-categories, helping the business evaluate instructor performance.
- Course Duration Analysis
Analyzes course duration and its relationship with views to understand how course length may relate to learner engagement.
- Interactive Filters & Slicers
Interactive slicers allow users to filter the dashboard by relevant categories and course attributes, making it easier to explore specific segments of the dataset.
